# TX Energia Solar

Landing page institucional da **TX Energia Solar** — empresa de energia fotovoltaica em Campos dos Goytacazes — RJ.

## Stack

- HTML5 + CSS3 + JavaScript vanilla
- Google Fonts (Inter + Space Grotesk)
- Font Awesome 6
- Deploy: Vercel

## Estrutura

```
.
├── index.html        # Página única (Hero, Calculadora, Sobre, Diferenciais, Projetos, FAQ, Mapa, CTA, Footer)
├── style.css         # Tema TX (azul #0F3F8F + laranja #F26B1F)
├── script.js         # Calculadora solar, FAQ accordion, navbar mobile, animações
└── images/
    └── logo.png      # Logotipo TX Energia Solar
```

## Desenvolvimento local

Basta abrir `index.html` no navegador, ou servir com qualquer static server:

```bash
npx serve .
# ou
python3 -m http.server 8000
```

Projeto otimizado para Vercel. Push para a branch principal e o deploy é automático.
